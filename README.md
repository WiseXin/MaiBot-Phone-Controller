# 手机管家（Phone Controller）插件

> 为麦麦（MaiBot）赋予操控一部真实安卓手机的完整自主能力。点按、按文字智能查找、滑动、中文输入、截屏直出聊天流、连招宏、录屏感知、QQ空间互动与网易云音乐联动。

---

## 一、特性概览

* 📱 **全面操控**：通过 ADB 无线调试控制受控手机，不需要 USB 数据线，只要在同一局域网或 Tailscale 虚拟局域网即可。
* 👁 **看屏与视觉感知**：
  * `phone_screenshot`：截取当前手机屏幕，自动压缩后直接发到群/私聊会话中，你和麦麦都能看懂。
  * `phone_dump`：将界面上的可交互节点全部结构化解析，提供精确文字与其中心坐标。
* 🎯 **按文字智能点击 (`phone_tap_text`)**：
  * 无需估算屏幕坐标，直接通过 `phone_tap_text("确认")` 或 `phone_tap_text("签到")` 自动寻找并点击按钮。
* ⌨️ **原生中文输入**：
  * 配合受控手机端的开源输入法 `ADBKeyboard`，通过 Base64 广播无缝输入任意中文、长句与表情符号。
* 🎬 **连招宏 (`phone_macro`)**：
  * 一次性顺序执行一组动作（点击、滑动、输入、延时），显著降低多轮对话网络开销与 Token 消耗。
* 🎥 **动态录屏感知 (`phone_record_screen`)**：
  * 调用手机端 `screenrecord` 录制 3~15 秒短视频，自动使用本地 `ffmpeg` 提取等间距关键帧发到聊天。
* 🎵 **网易云音乐控制**：
  * 支持查歌词、搜歌、查精选热评，通过多媒体键控制播放/暂停/切歌，支持在「一起听」房间自动发言。
* 🌐 **QQ 空间互动**：
  * 基于 OneBot 11（NapCat）原生接口，支持给好友点赞、查看空间动态、安全发布空间说说。

## 二、受控手机准备工作

### 1. 开启无线调试 (Android 11+)
1. 进入手机：`设置 → 关于手机 → 连续点击版本号 7 次` 开启开发者选项。
2. 进入：`设置 → 更多设置 / 系统 → 开发者选项`。
3. 开启 **「USB 调试」** 以及 **「无线调试」**。
4. 点击进入「无线调试」页面，查看当前手机分配到的 `IP:端口`。

### 2. 连接到麦麦
* **若手机与麦麦都在 Tailscale 组网中（推荐）**：
  手机 Tailscale IP 固定（如 `100.x.x.x`），在麦麦对话中直接唤起：
  ```
  连接手机无线调试：100.x.x.x，端口 38875
  ```
  或调用工具 `phone_connect(host="100.x.x.x", port=38875)`。

* **首次无线配对**：
  在手机「无线调试」页面点击「使用配对码配对设备」，获取配对端口与 6 位配对码，调用：
  `phone_pair(host="100.x.x.x", port=配对端口, code="123456")`，配对只需一次。

### 3. 支持中文输入（可选，强烈建议安装）
安卓原生 `input text` 不支持中文。如需在手机上打中文：
1. 下载开源 [ADBKeyboard.apk](https://github.com/senzhk/ADBKeyBoard/releases)。
2. 安装到受控手机，并在 `设置 → 语言与输入法` 中启用 `ADB Keyboard` 即可。

## 三、可用工具清单

| 工具名称 | 功能描述 |
| :--- | :--- |
| `phone_status` | 获取受控手机的连接状态、电量、亮屏、前台应用包名 |
| `phone_connect` | 连接指定的无线调试 IP 与端口 |
| `phone_pair` | 首次配对无线调试（输入 IP、端口与 6 位配对码） |
| `phone_screenshot` | 截取手机当前画面，并自动发到当前聊天流 |
| `phone_dump` | 导出屏幕 UI 布局树，获取所有文字与其点击坐标 |
| `phone_tap_text` | **智能点击**：根据界面文字寻找按钮并自动点击（推荐） |
| `phone_tap` | 按照 (x, y) 像素坐标点击 |
| `phone_swipe` | 滑动屏幕（支持 up向上翻页/down向下/left向左/right向右） |
| `phone_text` | 输入文本（中文通过 ADBKeyboard 广播发送） |
| `phone_key` | 系统按键模拟（back返回/home主页/enter回车/power电源） |
| `phone_open_app` | 启动应用程序（支持中文别名如 '网易云', '微信', 'B站'） |
| `phone_macro` | 连招宏执行（传入动作列表，串行执行） |
| `phone_record_screen`| 录制手机动态并自动抽帧成多张关键帧图片发送 |
| `music_lyrics` | 查询指定歌曲的歌词内容 |
| `music_control` | 控制手机网易云音乐播放（play_pause/next/prev） |
| `music_room_say` | 在网易云「一起听」聊天室自动打字发言 |
| `qzone_post_feed` | 在 QQ 空间发布一条新说说 |
| `qzone_like_feed` | 为指定的说说点赞 |
| `qzone_get_feeds` | 查看好友 QQ 空间最新动态 |

## 四、安全与权限保护

为防止他人或群友调戏麦麦随意操控你的手机，插件内置了**主人权限防线**：
* 只有在 `config.toml` 中配置的 `owner_qq`（你的 QQ 号）发出的控制指令才会被执行。
* 其他非主人用户调用任何控制工具均会被直接拦截，保障设备安全。
