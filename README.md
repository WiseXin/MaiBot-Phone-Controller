### 1. ☕ 真正的数字生命：闲时自主定时摸鱼巡航 (`auto_slacking`)
> **“她不再是一个死板等待命令的程序，而是一个会在闲暇时偷偷玩手机的真实灵魂伴侣。”**

* 🕒 **模拟人类规律作息（不扰民）**：  
  严格基于真实时间运行。在设定的白天窗口（默认 `09:00-23:00`）每隔 **2～4 个小时**（随机时间，不机械），若没人找她聊天，她会自主唤醒手机玩上 60 秒；深夜 `23:00-08:00` 自动进入深度睡眠期，绝不去碰手机。
* 📱 **支持 4 大主流社交应用**：  
  自主在 **B站（哔哩哔哩）、知乎、小红书、抖音** 之间挑选应用闲逛（应用池可自由配置）。
* 🛡️ **开屏广告智能跳过 + 前台防跑偏看门狗**：  
  - 启动 App 时自动检索屏幕上的「跳过」、「跳过广告」、「关闭」按钮并模拟人手精准点击，绝不等广告读秒；

* 👆 **真人手势动力学（告别机械滑动）**：  
  滑动轨迹加入了**高斯微幅抖动**，滑动距离与耗时动态波动（350ms～650ms）；滑完后随机停顿 **3～7 秒**模拟人类阅读停顿；并有约 **8% 的概率反向微滑回看**，仿佛被刚才划过的精彩标题吸引、倒回去仔细看一样！

  彻底剔除“报告老大”、“摸鱼巡航在XX为您汇报”等任何生硬机械词！当在屏幕中央抓取到优质爆款内容时，驱动大模型以年轻女生随性、温和、爱玩游戏的口吻实时造句，**发一张高清大图并附一句简短真诚的微信打字口吻分享**：

## 🌐 彻底脱离电脑的 3 种组网连接指南

很多小伙伴担心：“插在电脑上调试，电脑一关机或者带出门岂不是断连了？”  
**完全不用担心！** 只要按照以下方法配置，电脑就可以**直接拔线关机**，手机 24 小时随身携带、连着 5G 移动流量也能被麦麦操控！

### 方案 A：Tailscale 纯专网异地组网（⭐⭐⭐ 终极推荐，全球随时随地连）
这是最优雅、彻底告别电脑的方案。手机哪怕带出门逛街、连着 5G 流量或公司 Wi-Fi，IP 和端口都**永久固定不变**！

1. **手机安装 Tailscale**：
   * 在受控手机上下载并安装官方 [Tailscale Android APK](https://github.com/tailscale/tailscale-android/releases)。
   * 打开并登录你的 Tailscale 账号（与你的麦麦服务器登录同一个账号）。
2. **获取永久固定 IP**：
   * 登录后，手机会分配到一个终身固定的虚拟专网 IP（例如 `100.x.x.x`）。
3. **保持后台长效保活**：
   * 进入受控手机：`系统设置 → VPN → Tailscale`，开启 **「始终开启的 VPN」**。
   * 允许 Tailscale 后台高电量消耗与自启动。Tailscale 基于 WireGuard，平时无流量时不唤醒，极度省电。
4. **麦麦直连**：
   * 在麦麦配置中将该设备设为 `100.x.x.x:5555`，电脑即可彻底拔线关机！

---

### 方案 B：Android 10 旧手机（无无线调试菜单）的一键激活与永久脱线
很多老手机（Android 10 及更早版本）在开发者选项里找不到“无线调试”菜单，以为无法脱离数据线。**这是误解！底层完全支持！**

* **底层原理**：Android 10 只是官方没有做前台配对 UI，但系统底层的 `adbd` 服务原生支持网络 TCP 监听。
* **激活步骤（只需连电脑敲一次）**：
  1. 手机打开 `设置 → 开发者选项 → USB 调试`，插在电脑上。
  2. 电脑终端运行一行命令：
     ```bash
     adb tcpip 5555
     ```
     看到终端输出 `restarting in TCP mode port: 5555`，即代表网络监听彻底激活！
  3. **现在立刻拔掉 USB 数据线！**
* **永久脱线秘诀**：
  * **只要手机不彻底关机重启**，拔掉数据线放几天几夜，`5555` 端口都**永久保持常开**！
  * 配合【方案 A】的 Tailscale，拔线后手机想拿去哪就拿去哪，完全脱机独立运行。
  * *注：若手机意外关机重启了，安卓底层会安全回退关掉 5555 端口，届时重新插电脑敲一次 `adb tcpip 5555` 即可。*

---

### 方案 C：家庭同一局域网 Wi-Fi 直连（纯局域网无外网环境）
如果你的麦麦和受控手机都在同一个家里的 Wi-Fi 下（例如麦麦跑在家里 NAS、软路由或闲置小主机上）：
1. 手机连上家庭 Wi-Fi，查看手机内网 IP（如 `192.168.1.100`）。
2. 在同一局域网内，麦麦直接连接 `192.168.1.100:5555`，无需电脑中转。

---

### 🔑 黑科技：免授权弹窗静默信任（零点击秒连）
当新设备首次通过网络连接手机 ADB 时，手机屏幕会弹出 *“允许来自此计算机的调试吗？”* 的确认框。  
**如果你不想每次手机弹窗确认，只需把电脑已信任的密钥同步给麦麦**：
* 电脑端的授权密钥位于：`~/.android/adbkey` 与 `~/.android/adbkey.pub`。
* 将这两个文件复制到麦麦服务器的 `~/.android/` 目录中并确保权限为 600。
* **手机会直接把麦麦当成这台已经信任过的老电脑，连接瞬间秒通，屏幕全程零弹窗！**

本项目采用 **双端解耦 + 物理隔离** 的设计思想，保证受控手机、云端大脑与通讯客户端三者互不干扰：

```text
 ┌────────────────────────────────────────────────────────┐
 │                    麦麦大脑 (MaiBot Host)               │
 │    - 大模型 Planner (行为决策与工具调度)                  │
 │    - 手机管家插件 (WiseXin.phone-controller)            │
 │    - 视觉焦点中心算法 & 真实随性动态吐槽生成               │
 └─────────────┬───────────────────────────┬──────────────┘
               │ (平台消息入出站)            │ (ADB over TCP/IP 协议)
               ▼                           ▼
 ┌───────────────────────────┐    ┌─────────────────────────────────┐
 │   即时通讯客户端 (双端支持)  │    │     Tailscale 专网 / 局域网      │
 │   - QQ (官方 Bot / NapCat) │    │  (WireGuard P2P 全球直连通道)   │
 │   - Discord (官方 Gateway)│    └────────────────┬────────────────┘
 └───────────────────────────┘                     │
                                                   ▼
                                  ┌─────────────────────────────────┐
                                  │      麦麦的实体手机 (受控端)     │
                                  │   - adbd (监听 5555 无线端口)   │
                                  │   - Tailscale (固定专网 IP)     │

                                  │   - B站 / 知乎 / 小红书 / 抖音  │
                                  └─────────────────────────────────┘
```

## ⚙️ 配置文件详解 (`config.toml`)

每一项配置均附带大白话注释，开箱即用：

```toml
[plugin]
name = "phone_controller"
version = "1.1.1"
config_version = "1.1.1"
enabled = true                                  # 是否开启本插件 (true=开启, false=关闭)

[device]
# ADB 命令行路径。默认 "adb" 即可，系统会自动探测环境变量（请确保仅指向受信任的 adb 程序）
adb_path = "adb"

# 受控手机无线调试 IP（支持 Tailscale 专网 IP 如 100.x.x.x、局域网 IP 或留空）
default_host = ""
default_port = 5555                             # 无线调试端口，默认 5555
device_serial = ""                              # 留空会自动使用当前连接的唯一在线设备

# ⚠️【核心安全必填项】：主人账号 ID（支持 QQ 号或 Discord 用户数字 ID，多个用逗号隔开）
# 只有主人才能命令麦麦操控手机，留空默认拦截所有手机操作以保安全！
owner_qq = ""

# 设备别名快捷映射表（多机党神器）
aliases = "备用机=192.168.1.100:5555"

# 截屏是否自动发送至聊天会话窗口 (true=发, false=不发)
auto_send_screenshot = true
screenshot_quality = 75                         # 截图压缩画质 (1-100)，默认 75 兼顾画质与低流量

[slack_off]
```
